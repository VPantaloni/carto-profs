1À quoi sert Carto-profs ?

Vous avez dans Grist une table de personnes (professeur·es, formateur·trices, membres d’un groupe de travail…) avec l’UAI de leur établissement (on dit aussi RNE : 7 chiffres et 1 lettre, par exemple 0451234A). Carto-profs en fait une carte : un point par établissement, avec le nombre de personnes, des couleurs à votre choix, une fiche par établissement et des outils pour écrire aux personnes.

Vous n’avez rien à saisir : le widget retrouve seul la position des établissements dans les données ouvertes du ministère de l’Éducation nationale.

2Installer le widget dans Grist

  1. Ouvrez votre document Grist et la page qui contient la table des personnes.
  2. Cliquez sur Nouveau (en haut à gauche) puis Ajouter une vue à la page.
  3. Choisissez Personnalisé comme type de vue, et votre table comme données (« Sélectionner les données »).
  4. Dans le panneau de droite, choisissez URL personnalisée et collez l’adresse :
https://widget.forge.apps.education.fr/carto-profs/
  1. Toujours dans le panneau de droite, accordez l’accès Lire la table sélectionnée. C’est tout ce qu’il faut.
  2. La carte s’affiche. Au premier lancement, une fenêtre vous montre les colonnes reconnues (voir plus bas) et rappelle l’accès choisi. Si le widget n’a pas accès à la table, un message indique quoi régler.
Pour essayer sans vos données : importez dans Grist le fichier carto-profs-exemple.csv (données inventées) avec Nouveau → Importer depuis un fichier, puis suivez les étapes ci-dessus.

3Préparer la table

Une table toute simple suffit. Les noms des colonnes sont libres : le widget les devine.

Toutes les autres colonnes (grade, échelon, discipline, établissement…) restent disponibles pour les couleurs, les bulles et les filtres.

4Premier démarrage

Le widget lit la table et vous montre ce qu’il a reconnu : « UAI = Rne (99 % des valeurs au format UAI) », « Mail = mail_ouvert (contient des @) »… Corrigez si besoin avec les listes, puis cliquez sur Voir la carte. Une courte visite guidée présente ensuite les boutons (bouton « Ne plus montrer »).

Les UAI introuvables

Un bandeau orange en bas à gauche signale les lignes qui ne sont pas sur la carte. En cliquant dessus :

  • Format incorrect : il manque un chiffre, la lettre, ou il y a un espace. Corrigez la cellule.
  • Inconnu dans l’open data : l’établissement a fermé ou fusionné, ou l’UAI est mal saisi. Le lien « Chercher » ouvre l’annuaire de l’éducation.
  • Voir dans Grist sélectionne la ligne dans votre table pour la corriger.
Astuce pour « Voir dans Grist » : ajoutez à la page une vue Fiche (ou Table) de la même table et, dans son panneau de droite, Sélectionner par → Carto-profs. Le bouton crayon d’une personne affiche alors sa ligne, prête à être modifiée.

Vous pouvez aussi faire le lien entre les colonnes dans le panneau de droite de Grist (rubrique des colonnes du widget) : ce choix passe alors avant celui du widget.

5Lire la carte

  • Un point = un établissement. Le badge noir donne le nombre de personnes.
  • Camembert : si l’établissement a des personnes de couleurs différentes, le point montre la part de chaque couleur.
  • Groupes : en vue éloignée, les points proches se regroupent (rond bleu avec le total). Cliquez pour zoomer. La case « Regrouper les points proches » dans la légende le désactive.
  • Survol : nom, commune et nombre de personnes. Clic : la fiche de l’établissement à droite.

Le fond de carte clair ou sombre suit le réglage de votre ordinateur ; le bouton de thème le change.

À deux doigts (ou clic droit maintenu), on peut tourner et incliner la carte. La boussole en bas à droite remet le nord en haut et la carte à plat ; le bouton juste dessous (Voir tous les points) recadre la carte sur l’ensemble des points.

Zones de remplacement

Les titulaires sur zone de remplacement ont un UAI particulier : 6 chiffres, puis Z et une lettre (par exemple 037002ZK). Ces zones n’ont pas d’adresse : le widget les montre par une bulle en pointillés (« ZR 37 Ouest · 5 »), rangée autour des départements pour ne pas cacher la carte, avec un trait de rappel vers un point de la zone. Le côté vient du nom de la zone lu dans la colonne de l’établissement (« ZR INDRE ET LOIRE OUEST » → à gauche) ; sans indication, le bord le plus proche. Un clic ouvre la liste des personnes, comme pour un établissement. La case Groupes de ZR de la légende montre ou cache ces bulles.

Les contours des départements s’affichent pour les départements présents dans la table (case dans la légende).

6Colorier selon…

  1. Cliquez sur Colorier. Le widget a regardé vos colonnes et propose celles qui font de bonnes catégories, avec un aperçu : « 5 valeurs : Certifié (50), Agrégé (15)… ».
  2. Choisissez-en une, puis Suivant. Choisissez une palette (dont une adaptée au daltonisme) ; cliquez une pastille pour changer une couleur.
  3. Choisissez « Camembert » ou « Couleur la plus fréquente » pour les établissements mêlés, puis Appliquer à la carte.

Le choix actuel est toujours en haut de la liste. Pour revenir à une seule couleur : bouton Retirer les couleurs, ou la croix à côté du titre de la légende.

Une colonne de nombres ou de dates (échelon, année de titularisation…) donne un dégradé en 5 classes. Une colonne Couleur au format #rrggbb peut aussi imposer la couleur de chaque personne.

7Contenu des bulles

Le bouton Bulles règle ce que l’on voit, avec un aperçu sur un vrai établissement de votre table :

  • Survol : commune, type d’établissement, nombre de personnes.
  • Ligne d’une personne : cochez les colonnes à montrer et rangez-les avec les flèches ; le modèle se remplit tout seul, par exemple {Nom} {Prenom} — {Grade} · {nbre_heure} h. Vous pouvez l’écrire vous-même : le texte entre accolades est remplacé par la valeur de la colonne. Si une valeur est vide, le séparateur disparaît.
  • Liens et tri : lien « écrire » sur chaque personne, bouton « voir la ligne dans Grist », ordre des personnes.
Toutes les colonnes peuvent apparaître dans les bulles, y compris des informations personnelles (date de naissance, notes, téléphone…). Tout lecteur du document les verra : ne cochez que ce qui est utile.

8Chercher, filtrer, légende

  • Recherche (en haut à gauche) : un nom, un établissement, un UAI ou une commune ; flèches puis Entrée. La carte s’y place et ouvre la fiche.
  • Légende : cliquez une catégorie pour la masquer ou la montrer. Le nombre à droite compte les personnes.
  • Filtrer : choisissez une colonne (statut, département…) puis décochez des valeurs. « Retirer le filtre » remet tout.
  • Fond d’établissements (dans la légende) : affiche en gris tous les établissements d’une académie, filtrables par type (écoles, collèges, lycées, EREA) et par secteur (public, privé).

9Point de départ

Le bouton Départ place votre commune ou votre bureau (recherche d’adresse, ou clic sur la carte). La carte trace des cercles de 10, 20 et 50 km ; la fiche et la liste donnent la distance à vol d’oiseau ; le lien « Itinéraire » part de ce point. Ce réglage reste dans votre navigateur : chaque lecteur a le sien.

10Sélection et mails

Composer la sélection

  • Dans une fiche : cochez des personnes, ou la case du haut pour tout l’établissement.
  • Sur la carte : bouton Sélectionner, puis faites glisser un rectangle autour des établissements.
  • Dans la liste du tableau de bord : cochez des établissements.

Une barre en bas rappelle « Sélection : 7 personnes dans 3 établissements », avec Écrire…, Copier les adresses et la croix pour vider.

Écrire

  • À qui : la sélection, toutes les personnes affichées, les établissements (adresse de l’annuaire de l’éducation, sinon ce.UAI@ac-….fr), ou les personnes avec leur établissement en copie.
  • Les adresses sont en Cci par défaut : personne ne voit les autres adresses.
  • Les personnes sans adresse sont listées. Au-delà de 40 adresses, l’envoi est découpé en lots à ouvrir l’un après l’autre (limite des messageries).
  • Le message s’ouvre dans votre messagerie : rien n’est envoyé par le widget. Si rien ne s’ouvre, utilisez « Copier les adresses » et collez-les dans votre messagerie (webmail académique, par exemple).

11Groupes

Un groupe rassemble des personnes que vous voulez voir ensemble : formateur·trices, tuteur·trices, membres d’un groupe de travail… Chaque groupe a un nom, une couleur et une description. Une personne peut être dans plusieurs groupes.

Les groupes sont enregistrés dans deux tables du document, Carto_groupes et Carto_membres, créées par le widget la première fois. Il faut donc l’accès complet au document (panneau de droite de Grist, rubrique Accès).

Créer un groupe

  1. Bouton Groupes ; la première fois, Créer les tables.
  2. Sous « Nouveau groupe » : nom, couleur, description, puis Créer le groupe.

Ajouter des membres

  • Une personne : cherchez-la (barre de recherche), puis dans la fiche cliquez sur l’icône à côté de son nom et cochez le groupe.
  • Toute une sélection : barre de sélection → Ajouter à un groupe…
  • Une liste : dans la fenêtre Groupes, Ajouter des membres. Collez des mails (même copiés d’un champ « À : » de messagerie), des lignes « NOM Prénom », ou un tableau avec une ligne de titres (Nom, Prénom, Mail, UAI) ; ou déposez un fichier CSV. Puis Chercher les correspondances.
  • Trouvée : ajoutée si vous validez. À vérifier (homonymes, nom approché, même nom mais mail différent) : choisissez la bonne personne dans la liste, ou « Ne pas ajouter ».
  • Introuvable : si la ligne contient un UAI, vous pouvez l’ajouter hors table (une personne d’une autre discipline, un·e CPE…) : elle est placée sur la carte à son établissement.
  • Une personne déjà dans le groupe n’est jamais ajoutée deux fois.

Voir les groupes sur la carte

Voir les groupes sur la carte (ou Colorier → Groupes) : chaque membre prend la couleur de son groupe, en camembert s’il est dans plusieurs. Les autres personnes sont en gris (« Hors groupe » dans la légende) : cliquez sur « Hors groupe » pour les cacher, ou sur un groupe pour le cacher.

Gérer, exporter

Pour chaque groupe : Membres (liste, retrait d’un membre), modifier (nom, couleur, description), CSV des membres, supprimer (deux clics : le groupe et ses membres). Les tables Carto_groupes et Carto_membres se consultent et se modifient aussi directement dans Grist.

Les membres sont retrouvés par leur mail ou leur nom : quand la table des professeur·es est remplacée l’année suivante, les groupes suivent sans rien refaire.

12Tableau de bord, liste et exports

Tableau de bord : personnes par département, par type d’établissement, par catégorie.
Liste des établissements, triable, utilisable au clavier (alternative à la carte).
Exporter : image PNG avec légende, CSV des établissements (avec coordonnées) ou des personnes, impression A4 paysage.
Présentation : plein écran sans menus, pour une réunion. Échap pour quitter.
Colonnes : revoir les colonnes utilisées, les UAI introuvables, et (option) écrire les coordonnées dans la table.
Thème : automatique, clair ou sombre.

Le (?) bleu en haut à droite relance la visite guidée, ouvre ce tutoriel et liste les nouveautés.

13Partager, droits, confidentialité

  • Droits du widget : « Lire la table sélectionnée » suffit. Le widget ne crée rien et n’écrit rien dans le document.
  • Groupes : deux tables Carto_groupes et Carto_membres dans le document ; accès complet nécessaire. Sans groupes, la lecture suffit.
  • Option « Écrire les coordonnées » (bouton Colonnes) : ajoute deux colonnes Latitude et Longitude à la table et les remplit. Elle demande l’accès complet au document : à n’activer que si vous en avez l’usage.
  • Réglages partagés : couleurs, bulles, fond d’établissements… sont gardés dans le document. Tous ses lecteurs voient la même carte. Seules les personnes qui peuvent modifier le document les enregistrent ; un lecteur peut les changer pour sa session.
  • Préférences personnelles (point de départ, thème, visite guidée) : gardées dans votre navigateur.
  • Partager la carte : partagez le document Grist en lecture (bouton Partager de Grist). Le widget marche pour un lecteur sans droit d’écriture.
  • Ce qui sort du navigateur : seulement les UAI, envoyés aux données ouvertes de l’Éducation nationale pour trouver les positions, et l’adresse tapée pour le point de départ (service d’adresses de l’IGN). Les noms, mails et autres colonnes ne quittent jamais votre ordinateur. Une copie des positions des établissements (pas des personnes) est gardée 30 jours dans le navigateur.

14En cas de souci

La carte reste vide, les menus sont vides

Le widget ne reçoit pas les lignes de la table. À l’installation, Grist laisse l’accès sur « Aucun accès » : dans le panneau de droite, rubrique Accès, choisissez « Lire la table sélectionnée » (ou « Accès complet au document » pour les groupes). Vérifiez aussi que la vue est liée à votre table (panneau de droite → Données). Un message en bas à gauche indique ce cas. Ensuite, le bouton Colonnes doit montrer la colonne UAI.

« Les données ouvertes ne répondent pas »

Le site data.education.gouv.fr est momentanément indisponible ou bloqué par votre réseau. Cliquez sur « Réessayer l’open data » plus tard. Les établissements déjà trouvés restent affichés (copie du navigateur).

Un établissement est mal placé

La position vient de l’open data. Pour la corriger, ajoutez des colonnes Latitude et Longitude à la table et remplissez-les pour cette ligne : elles passent avant l’open data.

Le bouton « Écrire » n’ouvre rien

Votre navigateur n’a pas de messagerie par défaut. Utilisez « Copier les adresses » et collez-les dans votre messagerie, en Cci.

Mes réglages ne sont pas gardés

Vous n’avez que le droit de lecture sur le document : demandez à son propriétaire de faire les réglages, ou de vous donner le droit de modifier.
