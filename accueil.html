Carto-profs

La carte interactive de vos professeur·es, formateur·trices ou groupes de travail, directement dans Grist. Il suffit de l’UAI de leur établissement : le widget retrouve seul les positions dans les données ouvertes de l’Éducation nationale.

Démarrage rapide

Votre carte en 5 minutes, avec votre table ou avec des données d’exemple inventées.

  1. Préparer une table de personnesUne colonne avec l’UAI (RNE) de l’établissement suffit ; nom, prénom et mail sont conseillés. Pour essayer : télécharger carto-profs-exemple.csv, puis dans Grist : Ajouter → Importer depuis un fichier.
  2. Ajouter une vue PersonnaliséDans la page de la table : Nouveau → Ajouter une vue à la page → type Personnalisé, données : votre table.
  3. Coller l’adresse du widgetPanneau de droite → URL personnalisée : l’adresse ci-dessous.
  4. Accorder l’accèsLire la table sélectionnée suffit pour la carte ; Accès complet au document pour les groupes de personnes.
  5. Se laisser guiderLe widget reconnaît vos colonnes et propose une visite guidée ; le bouton (?) en haut à droite rouvre la visite et le tutoriel.

Ce que fait Carto-profs

Pensé pour des personnes qui débutent avec Grist : des assistants plutôt que des réglages.

Placement automatique

Un point par établissement, retrouvé par l’UAI en open data ; badge du nombre de personnes, regroupement des points proches.

Colorier selon…

Le widget propose les colonnes qui font de bonnes catégories (grade, discipline…) ; camembert quand les couleurs se mêlent, légende cliquable.

Fiches et bulles

Fiche de chaque établissement avec ses personnes, au format choisi avec un aperçu en direct ; site, itinéraire, ligne dans Grist.

Groupes

Formateur·trices, tuteur·trices… : collez une liste de mails ou de noms, le widget retrouve les personnes et vous fait valider les doutes.

Sélection et mails

Entourez des établissements ou cochez des personnes, puis écrivez-leur (ou à leur établissement) depuis votre messagerie, en Cci.

Distances et zones

Point de départ avec cercles de 10, 20, 50 km ; zones de remplacement rangées autour des départements ; contours des départements.

Tableau de bord

Personnes par département, par type d’établissement, par catégorie ; liste accessible au clavier.

Exports et présentation

Image PNG avec légende, CSV, impression A4, mode plein écran pour une réunion.

Vos données

Ce qui sort de votre navigateur

  • Seulement les UAI, envoyés aux données ouvertes de l’Éducation nationale pour trouver les positions.
  • Jamais les noms, mails ou autres colonnes. Les mails s’ouvrent dans votre messagerie : le widget n’envoie rien.

Droits

  • Lire la table sélectionnée : la carte ; le widget ne modifie rien.
  • Accès complet : seulement pour les groupes (deux tables créées dans le document) ou pour écrire les coordonnées.
  • Les réglages suivent le document : tous ses lecteurs voient la même carte.
