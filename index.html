Démonstration avec des données fictives : ajoutez ce widget dans Grist pour voir vos données.

Le widget n’a pas encore accès à la table

  1. Cliquez sur cette vue, puis ouvrez le panneau de droite de Grist (« Widget personnalisé »).
  2. Dans la rubrique Accès, choisissez Lire la table sélectionnée.
  3. Choisissez Accès complet au document seulement si vous voulez écrire les coordonnées dans la table.

Aide détaillée : bouton (?) en haut à droite.
